# Security policy

## Supported versions

Only the latest release gets security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/tinwritescode/udownloader/security/advisories/new), not as a public issue. Include the steps to reproduce and the uDownloader and browser versions.

You can expect a first reply within 7 days. Once a fix is released, the advisory is published with credit to the reporter unless you'd rather stay anonymous.

Issues of particular interest: a web page making the extension fetch or save something the user didn't choose, leaking data across tabs or incognito, or reading local files.
